# How To: Software Engineer 📱

**How To: Software Engineer** is a concept iOS app I built in 2018 as part of an independent study at San Francisco State University. The app was designed to guide aspiring software engineers—especially those from nontraditional backgrounds—through curated resources, career timelines, and a mentor/mentee matching feature.

> ⚠️ Note: This project was never publicly launched and exists as a functional prototype built for academic purposes only.

## Features
- Curated CS/Software Engineering learning resources
- Mentor/mentee matching system
- Career roadmap and role-based guidance
- User profiles and private messaging
- Admin moderation tools

## Tech Stack
- **Frontend**: Swift, UIKit, Core Data
- **Backend**: Firebase (Authentication, Firestore)
- **APIs Used**: YouTube, Goodreads, Unsplash
- **Architecture**: MVC
- **Version Control**: Git + GitHub
